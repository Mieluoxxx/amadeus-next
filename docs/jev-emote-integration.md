# Jev 模型复用方案：E-mote 实时微表情驱动与声画协同架构

本文档规划将 **Jev 模型（快慢双系统中的 System 1 判别与路由引擎）** 深度复用于桌面伴侣的 **E-mote 角色表情驱动管线** 与 **声画多模态协同系统**，构建毫秒级前置本能反应、声画情感路由器、提示词解耦与连续微表情动力学。

---

## 1. 架构动机与理论依据

在认知科学与数字人交互体系中：
* **言语表述属于慢系统（System 2）**：深思熟虑、逻辑推演，生成首字时延（TTFT）通常在 500ms ~ 1500ms 之间。
* **面部反应属于快系统（System 1）**：本能性微表情（如被夸奖时的瞬间羞赧、听到荒谬论点时的瞬间挑眉）通常在刺激发生后 **50ms ~ 100ms** 内无意识触发。

当前系统完全依赖主力 LLM 在生成文本流中通过 `[EMO preset=NAME]` 标注表情，存在三大工程缺陷：
1. **时序滞后**：角色在主力模型完成推理前处于呆板静止或无意义的通用思考态，严重破坏真实生命感。
2. **格式脆弱与幻觉**：依赖 Prompt 约束易导致标签漏标、标签错配（如将傲娇心口不一误判为真的发怒 `angry`）。
3. **声画割裂**：E-mote 的 8 种离散立绘与 Fish Audio 的 71 种声学标记缺乏统一调度中枢。

Jev 具备 **10 ~ 25ms 极速响应**、**数学标定概率分布（`noul` $\in [0, 1]$）** 与 **低资源占用** 特性，是充当 E-mote 视觉本能控制器的最佳组件。

## 3. 四大核心复用集成方案

### 3.1 零延迟前置本能微表情 (Pre-emptive Instinctive Reflex)
* **目标**：消灭用户结束说话至主力 LLM 吐出首个 Token 之间的“交互冷场盲区”。
* **机制**：
  1. 用户语音 ASR 结束（Turn Begin）的瞬间，立即将用户输入推送至 Jev 进行情绪极性判别；
  2. Jev 在 **25ms 预算内** 输出针对用户输入的心理反应倾向：
     - 用户直球称赞/调侃（Valence > 0.8, Personal Arc） $\to$ `shy: 0.92` $\to$ **在 LLM 开始生成前瞬间脸红偏头**；
     - 用户提出颠覆性理论/反直觉论点 $\to$ `surprise: 0.88, serious: 0.75` $\to$ **瞬间挑眉微张嘴、眼神聚焦**；
     - 用户诉说实验失败/挫折 $\to$ `empathetic: 0.84, sad: 0.70` $\to$ **瞬间眉角微压流露关切**。
  3. 主力 LLM 生成的首句开始播报时，前置微表情平滑过渡至正式台词表情。

### 3.2 声画多模态情绪路由器 (Multimodal Emotion Router)
* **目标**：打通 Fish Audio 71 种细粒度声学标记与 E-mote 8 种离散表情之间的粒度代差。
* **机制**：
  1. Jev 对生成的台词语义进行多标签概率映射，一次推理输出两组控制契约：
     - **声学控制序列（发往 Fish Audio）**：注入情绪引导（如 `[disdainful]`）、副语言动作（如 `[sighing]` 叹气）、语气偏置（如 `[soft tone]`）与 Prosody 语速；
     - **视觉表情序列（发往 E-mote）**：映射为核心时间线标签（如 `表情_睨む`），并通过 `AlignmentTimeline` 结合音频真实时间戳触发。
  2. 实现叹气声与挑眉动作在毫秒级完全对齐，消除立绘在笑但声音在叹气的声画错位。

### 3.3 提示词解耦与人设守护纠偏 (Promptless Decoupling & Guardrail)
* **目标**：彻底免除主力 LLM 手动打标负担，消除格式幻觉，防范出戏（Out-of-Character）。
* **模式 A（完全免打标模式 · Promptless）**：
  - Prompt 契约中删除全部 `[EMO preset=...]` 语法规范，主力 LLM 仅需专注于生成最自然、地道的高质量文本；
  - 流式分词器将生成的文本句子直接交由 Jev 判别，自动推导出表情并注入管线。
* **模式 B（情绪校验护栏 · Emotion Calibrator）**：
  - 若保留 LLM 打标，Jev 充当运行时 Verifier；
  - 当 LLM 输出 `angry`，但台词语义实为傲娇掩饰时（$P(\text{angry}) < 0.25$ 且 $P(\text{shy}) > 0.80$），Jev 触发校验熔断，强行纠偏为 `shy`，防止破坏牧濑红莉栖的傲娇核心人设。

### 3.4 数学标定概率驱动连续微表情 (Continuous Intensity & Blending)
* **目标**：打破 8 种离散表情非黑即白的机械切帧，实现连续深浅与复合神态。
* **机制**：
  1. **强度连续调节（Expression Intensity）**：
     - 利用 Jev 经过严格数学标定的概率值 $p \in [0, 1]$ 作为 E-mote 变量缩放因子；
     - 同样是 `shy`（害羞），$p_{\text{shy}} = 0.35$ 仅触发极浅红晕，而 $p_{\text{shy}} = 0.95$ 则通过 `player.setVariableDiff` 驱动最深脸红与大幅度视线躲闪。
  2. **双重复合情绪融合（Composite Blending）**：
     - 识别混合情绪：如 $p_{\text{serious}} = 0.60$（学术严谨）叠加 $p_{\text{smile}} = 0.40$（被对方敏锐打动的欣慰）；
     - 底层在保持 `表情_睨む` 基础姿态的同时，动态微调嘴角与眼神差分变量，呈现出“既严厉又带有一丝赞许”的高级复合表情。

## 5. 性能与安全基准 (SLA)

1. **时延预算（Hard Latency Budget）**：
   - Jev 前置本能判别全链路耗时必须 $\le 30\text{ms}$，超时直接放弃前置反应，保持平滑降级。
2. **状态纯净性（Stateless & Idempotent）**：
   - 微表情仅作为瞬态表现，不污染核心对话历史，不向磁盘写日志。
3. **安全回滚**：
   - 若 Jev 返回置信度低于门限（最高项置信度 $< 0.40$），默认平滑退回 `neutral`，杜绝产生怪异抽搐。
