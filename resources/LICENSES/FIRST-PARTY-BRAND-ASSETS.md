# First-party brand asset record

The Amadeus project owner and maintainer confirmed on 2026-08-29 that the
following checked-in assets are their original works:

- `scene/room/background.png` (formerly `assets/images/amadeus_desktop_wallpaper.png`)

They are included in the Amadeus source release as first-party brand assets
under the repository root `LICENSE` (Apache License 2.0). This record does not
cover character art, model packs, ambient derivatives, scenario images,
reference voices, model weights, or any other separately inventoried external
asset.

Application icon sources (`amadeus_icon.ico`, `amadeus_icon_256.ico`,
`assets/icons/app/app_icon.ico`) are first-party original works, recorded as
such in the parent Code-Amadeus/Amadeus project's `LICENSES/provenance.json`.
They are not checked into this repository, so packaging falls back to the
electron-builder default icon.
